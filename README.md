# 耿萁鸿 · Concept Art Portfolio

React + Vite 单页作品集基础版，优先适配 PC，内容最大宽度 1700px，并包含手机端布局。

## 启动

需要 Node.js 20.19+ 或 22.12+，以及 pnpm。

```sh
pnpm install
pnpm dev
```

访问终端显示的地址，默认是 http://127.0.0.1:5173/ 。

```sh
pnpm build
pnpm preview
```

生产文件输出到 `dist/`，可部署到任意支持静态网站的托管服务。本次仅提供本地预览，未发布到公网。

本环境通过 `pnpm-workspace.yaml` 将 esbuild 替换为同版本 WebAssembly 实现，避免 Windows 受限目录下的原生进程路径解析问题；不影响网站功能。

## 已实现

- 全屏视频 Hero：静音自动播放、循环、播放/暂停、静态封面、导航和联系入口。
- 个人介绍、角色人物图、教育与项目经历、联系方式、简历 PDF。
- 七个独立项目 Works，十五个项目内章节、55 张详情图；支持项目详情、章节跳转、阶段说明和 Esc 关闭。
- 四张能力卡片和软件技能列表。
- 整屏联系页：发送邮件、复制邮箱、拨打电话和 ArtStation 链接。
- 手机菜单、键盘焦点、对话框焦点约束及减少动态效果偏好适配。
